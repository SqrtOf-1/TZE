# TZE — Tiny Zelda Engine

**TZE (Tiny Zelda Engine)** is a custom 3D game engine written in C++20.

The project aims to build a lightweight, modular and cross-platform game engine.

## Goals

- Custom 3D mathematics library
- 3D rendering with OpenGL ES 3.1
- Window and input management with SDL3
- Scene management and component system
- Custom visual editor
- Separate Editor and Runtime applications

## Technology Stack

- **Language:** C++20
- **Build system:** CMake
- **Windowing and input:** SDL3
- **Graphics API:** OpenGL ES 3.1
- **Editor UI:** Dear ImGui

## Project Status

**Early development — Work in progress**

TZE is currently in its foundational stage. The mathematics library and core engine architecture are under development.
